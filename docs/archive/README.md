# Архив документации

Здесь лежат исторические документы, которые **больше не поддерживаются в актуальном
состоянии**. Они сохранены, потому что объясняют, почему ранние решения были приняты
именно так, но опираться на них при работе с текущим кодом нельзя.

## Сводки сессий (июнь 2026)

`session_summary_2026-06-*.md` — шесть подробных отчётов по сессиям Этапов 6–7. На тот
момент проект был на Streamlit, а обработка шла через граф LangGraph; и то, и другое с тех
пор заменено (React + FastAPI, LLM-оркестратор с tool-calling). Их содержимое перекрыто
журналом `docs/progress.md`, который ведётся по сессиям и остаётся источником правды по
истории.

## `queries_for_n8n.md`

Функции `queries.py` под автоматизацию через n8n cloud. n8n в проекте не используется —
расписания гонит встроенный APScheduler (`api/scheduler.py`). Часть описанных функций
(в т.ч. `get_notifications_due_now`) удалена вместе с мёртвым путём уведомлений v0 (P2-4).
